02 · Contenido del curso

Temas estudiados en el semestre

Resumen de los módulos vistos durante el curso, organizados por unidad temática.

Módulo 1

Historia de la Computadora

La computadora ha evolucionado desde enormes máquinas mecánicas del siglo XIX hasta los dispositivos portátiles actuales. Esta evolución se divide en generaciones: las primeras usaban tubos de vacío (1940s), luego transistores, circuitos integrados, microprocesadores y hoy en día inteligencia artificial. Cada generación trajo mayor velocidad, menor tamaño y menor costo.

ENIAC Generaciones Von Neumann
Módulo 1

Hardware

El hardware son todos los componentes físicos de una computadora. Se divide en dispositivos de entrada (teclado, ratón), procesamiento (CPU, RAM), almacenamiento (disco duro, SSD) y salida (monitor, impresora). La CPU es el "cerebro" que ejecuta instrucciones, mientras que la RAM almacena datos de uso temporal para mayor velocidad.

CPU RAM SSD Periféricos
Módulo 1

Arquitectura de Computadoras

La arquitectura de computadoras describe cómo están organizados e interconectados los componentes internos. El modelo más conocido es el de Von Neumann, que separa la memoria de los datos y las instrucciones. Define conceptos como el bus de datos, la ALU (Unidad Aritmético-Lógica), registros y ciclos de instrucción (fetch-decode-execute).

Von Neumann ALU Bus
Módulo 1

Hardware y Software

El hardware es la parte física; el software es la parte lógica (programas e instrucciones). El software se clasifica en: software de sistema (sistema operativo), software de aplicación (Word, Chrome) y software de desarrollo (editores de código). Ambos trabajan juntos: el hardware ejecuta lo que el software le indica.

S. Operativo Apps Drivers
Módulo 1

Sistema Operativo

El sistema operativo (SO) es el software principal que gestiona todos los recursos del equipo y sirve de intermediario entre el usuario y el hardware. Sus funciones incluyen administración de procesos, memoria, archivos y dispositivos de entrada/salida. Los SO más conocidos son Windows, macOS y Linux. En móviles: Android e iOS.

Windows Linux Procesos
Módulo 1

Introducción a Bases de Datos

Una base de datos es un conjunto organizado de información estructurada. Los sistemas gestores de bases de datos (SGBD) permiten crear, consultar, modificar y eliminar datos. SQL es el lenguaje estándar para bases de datos relacionales. Las tablas se relacionan mediante claves primarias y foráneas para evitar duplicar información.

SQL Tablas MySQL
Módulo 2

Sistemas de Numeración

Las computadoras trabajan internamente con el sistema binario (base 2), usando solo 0 y 1. También se utilizan el octal (base 8) y hexadecimal (base 16) para representar datos de forma más compacta. Saber convertir entre bases es fundamental: por ejemplo, el número decimal 10 equivale al binario 1010 y al hexadecimal A.

Binario Hexadecimal Conversión
Módulo 2

Introducción a Redes

Una red de computadoras conecta dispositivos para compartir recursos e información. Las redes se clasifican por tamaño: LAN (red de área local), MAN (metropolitana) y WAN (área amplia, como internet). El protocolo TCP/IP define cómo se transmiten los datos. Cada dispositivo tiene una dirección IP única que lo identifica en la red.

TCP/IP LAN / WAN IP
Módulo 2

Protocolos de Red y Seguridad LAN

La seguridad en redes protege la información de accesos no autorizados. Los protocolos como HTTPS, SSH y TLS cifran las comunicaciones. En redes LAN se utilizan firewalls, VLANs y control de acceso para aislar el tráfico. Las amenazas más comunes incluyen phishing, malware y ataques de denegación de servicio (DoS).

Firewall HTTPS VLAN
Módulo 3

Desarrollo de Páginas Web

El desarrollo web utiliza tres tecnologías base: HTML (estructura del contenido), CSS (estilos y diseño visual) y JavaScript (interactividad y comportamiento). HTML usa etiquetas para definir elementos; CSS aplica colores, fuentes y layouts; JavaScript permite animaciones, formularios dinámicos y comunicación con servidores. Este mismo sitio fue construido con esas tres tecnologías.

¿Cómo se utilizó la IA?

Las herramientas de inteligencia artificial se utilizaron como apoyo para redactar y revisar explicaciones de los temas del curso, asegurando que el contenido fuera claro y preciso. También apoyaron en la generación del código HTML y CSS del sitio, la organización visual de la información y la verificación de conceptos técnicos.

Es importante aclarar que el contenido publicado fue comprendido y revisado por el equipo, utilizando la guía didáctica del curso como referencia principal. La IA funcionó como una herramienta de apoyo, no como fuente de conocimiento única.

  • Claude (Anthropic)
    Generación de código HTML/CSS, redacción de contenido técnico y revisión de explicaciones.
  • ChatGPT (OpenAI)
    Consultas sobre conceptos de redes, bases de datos y sistemas operativos.
  • Google Gemini
    Búsqueda de recursos multimedia y verificación de información técnica actualizada.
  • Canva AI
    Apoyo en decisiones de diseño visual y organización de la información.

05 · Cierre

Conclusión del proyecto

Lo aprendido en este semestre

El curso de Introducción a los Sistemas de Cómputo nos permitió comprender el funcionamiento completo de una computadora: desde su historia y componentes físicos, hasta los sistemas operativos, bases de datos, redes y el desarrollo web. Cada tema se conecta con el siguiente, formando una visión integral de cómo funciona la tecnología que usamos a diario. Este texto paralelo busca ser una referencia útil y organizada de todo ese conocimiento, presentado de manera accesible y visual.
